# AGENTS.md (kirkova-models)

Guidance for people and AI coding assistants contributing to this public repository.

## About this repository

The training and evaluation code behind Kirkova's predictions, our published papers, accuracy reports and the history of every model we have trained.

## Contributing

- **Open an issue first** for anything bigger than a typo, so we can agree on the direction.
- Keep changes small and focused; explain *what* changed and *why* in the pull request.
- Be precise and honest. This repository is how we show our work: corrections are welcome and are published openly, never quietly rewritten.
- Run the checks described in the README before you open a pull request.

## Please do not include

- Secrets of any kind: keys, tokens, passwords, webhook URLs.
- Personal or customer data, including in issues, logs and screenshots.
- Anything you do not have the right to share.

## Security

Do not report vulnerabilities in public issues. See the [security policy](https://github.com/kirkovasports/.github/blob/main/SECURITY.md).

Predictions and picks are for entertainment only, not betting or financial advice.
